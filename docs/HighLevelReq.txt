#Client
-------------

Req01. | The be Client shall be a user-friendly GUI with three buttons 
and a clickable layer, implemented using PyQt6:

- Requesting temperature
- Toggling Relay
- Establish/Closing session
- Clickable layer to clear logs

Req02. | Communication
The Client shall send requests to the Server for:

- Session establishment
- Temperature reading
- Relay control
- Clearing the data

The Client shall receive responses from the Server and update the GUI.

Req03. | Security 

The Client shall use a secure connection to the Server.

There shall be mbedtls library used to encrypt and decrypt:

▪ SHA256: For hashing 
▪ HMAC-SHA256: For message authentication 
▪ AES-256: For symmetric encryption 
▪ RSA-2048: For asymmetric key exchange 
◦ Using Fj2-;wu3Ur=ARl2!Tqi6IuKM3nG]8z1+ as the shared HMAC secret key 
◦ Using RSA-2048 for secure exchange of AES-256 key and initialization vector 
◦ Protect all transactions with HMAC-SHA256 

#Server
-------------

Req04. | There shall be session timeout after 1 min

Req05. | Communication:

-Receive and process requests from clients.
-Send responses to clients, including:
◦ Session establishment/termination acknowledgments
◦ Temperature readings
◦ Relay control confirmations

Communication Protocol: 
The server and client shall communicate over serial (UART). 
The client should allow the user to specify the serial port and baud rate when launching the application. 

Req06. | Security:

- Implement the same security as the client.
- Validate incoming requests and responses.

Req07. | The server shall interact with the ESP32 to:

- Read temperature
- Control the relay
